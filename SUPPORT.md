# Support

- Ask setup and usage questions in [GitHub Discussions](https://github.com/ellelion/botteams/discussions).
- Report a reproducible website bug with the bug issue form.
- Propose a team or bot with the listing issue form or open a pull request.
- Report documentation drift with the documentation issue form.
- Report security problems privately through [SECURITY.md](./SECURITY.md).

Please do not use public issues for account credentials, private company data,
or vulnerability details. botteams.ai does not control Grok Bot accounts or
xAI connector access.
