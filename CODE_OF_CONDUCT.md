# Code of Conduct

## Our standard

We want a useful, safe, and welcoming project. Be direct about the work and
respectful toward the person doing it.

Good participation includes:

- Giving specific, actionable feedback.
- Explaining technical claims with evidence.
- Accepting a clear "no" without personal attacks.
- Protecting private information and reporting security issues privately.
- Making space for contributors with different experience levels.

Unacceptable participation includes harassment, discrimination, threats,
sexualized attention, deliberate disruption, doxxing, spam, and repeated
personal attacks.

## Scope

This code applies in issues, pull requests, discussions, and other project
spaces. It also applies when someone represents this project elsewhere.

## Enforcement

Report conduct concerns to info@ellelion.com. Do not post private evidence in a
public issue. Ellelion LLC will review reports privately and may edit or remove
content, issue a warning, limit participation, or ban an account.

Anyone involved in a report must step out of the enforcement decision. We will
share only the information needed to investigate and act.
