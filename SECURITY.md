# Security Policy

## Supported version

Only the latest commit on `main` is supported. This website is deployed from
`main`, so security fixes are not maintained on older branches.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ellelion/botteams/security/advisories/new).
If that form is unavailable, email info@ellelion.com.

Do not open a public issue for a suspected vulnerability. Include the affected
route or file, impact, reproduction steps, and any safe proof of concept. Do
not include real user data, credentials, or destructive test results.

We aim to acknowledge a report within three business days and provide an
initial assessment within seven business days. We will coordinate disclosure
after a fix is available.

## Safe research

Good-faith research that avoids privacy violations, data destruction, service
disruption, and access beyond what is needed to show the issue is welcome. Give
us reasonable time to fix a confirmed issue before public disclosure.
